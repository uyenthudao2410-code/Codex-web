# 17. Final scientific verdict for P1

P1 now establishes all of the following:

- causal denominators are explicit rather than reconstructed after seeing outcomes;
- missing controller cost, token and quality telemetry remain unknown rather than zero/good;
- historical uncertainty is retained instead of backfilled;
- lifecycle acceptance is not treated as post-accept quality evidence;
- host correlation requires explicit server-owned identity;
- routing/placement regret requires real representative comparable pairs;
- multi-objective trade-offs remain visible without invented scalar utility;
- measurement readiness never grants routing/placement promotion authority automatically.

P1 does **not** establish:

- Mini or Luna efficacy relative to deterministic MCP;
- server-first efficacy relative to local-first placement;
- cost per accepted result for candidate routes;
- quality non-inferiority for candidate policies;
- model/provider latency from DOM-visible timing;
- causal improvement in legacy UNKNOWN observations.
