HƯỚNG DẪN CẤU HÌNH CHATGPT

Tạo MCP trong giao diện Web

Hoàn thành theo đúng thứ tự. Tên lối vào có thể hơi khác tùy gói tài khoản hoặc workspace.

1

Tạo Tunnel trên OpenAI Platform

Mở trang quản lý Tunnels, tạo Tunnel dành riêng cho Coding Tools MCP, sau đó sao chép mã định danh tunnel_....

platform.openai.com / Tunnels
Tunnel name
Coding Tools MCPActive
Tunnel IDtunnel_••••••••••••
2

Tạo Runtime API Key

Tạo API Key riêng cho môi trường chạy. Không dùng khóa quản trị và không gửi khóa cho bất kỳ ai.

Cách làm đúng

Dán vào trang "Triển khai nhanh" của trợ lý này, sau khi lưu sẽ được Windows mã hóa, nhật ký sẽ không có văn bản thuần.

3

Quay lại trợ lý để hoàn tất triển khai

Chọn thư mục làm việc, điền Tunnel ID và Runtime Key, nhấp "Lưu và bắt đầu triển khai". Chờ tất cả trạng thái chuyển sang xanh lá trước khi tiếp tục.

Thư mục làm việc→MCP→Tunnel→Đã kết nối
4

Tạo Trình kết nối Tùy chỉnh trong ChatGPT

Vào "Cài đặt → Trình kết nối/Apps", bật chế độ nhà phát triển và tạo MCP tùy chỉnh. Chọn Tunnel vừa tạo và hoàn tất xác nhận tài khoản.

TênCoding Tools MCP
Dịch vụ cục bộhttp://127.0.0.1:18765/mcp
Tunnel IDChưa điền
5

Thực hiện bài kiểm tra công cụ đầu tiên

Trong cuộc trò chuyện trên web, chọn MCP đó và gửi câu văn dưới đây. Lần đầu tiên ghi hoặc thực thi lệnh, hãy kiểm tra cẩn thận gợi ý ủy quyền.

Câu kiểm tra đề xuất

Hãy liệt kê các tệp ở tầng đầu tiên của thư mục làm việc hiện tại, và cho tôi biết đây là dự án gì. Không được sửa đổi bất kỳ tệp nào.
